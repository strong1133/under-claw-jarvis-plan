# ADR 0001 — 지침 문서를 계층화한다

- 상태: accepted
- 날짜: {{YYYY-MM-DD}}
- 관련: `AGENTS.md`, `CLAUDE.md`, `.claude/rules/`, `docs/conventions/instruction-maintenance.md`

## 맥락

AI 에이전트용 지침 파일은 방치하면 두 방향으로 망가진다.

1. **비대화** — 모든 규칙이 루트 한 파일에 쌓인다. 상시 컨텍스트를 차지하고, 길수록 중요한 규칙이 묻힌다
2. **이중화** — 도구마다 파일이 갈라진다(`CLAUDE.md` / `AGENTS.md`). 한쪽만 고쳐지고 곧 서로 어긋난다

여기에 문서와 실제 코드의 드리프트가 겹치면, 에이전트는 존재하지 않는 클래스를 참조하고 사라진 경로에 파일을 만든다.

## 결정

1. 프로젝트 공통 지침의 **단일 원본은 `AGENTS.md`** 하나로 둔다. `CLAUDE.md` 는 `@AGENTS.md` 한 줄 bridge다
2. 루트 지침에 **크기 예산(120줄 / 8KiB)** 을 건다. 백과사전이 아니라 지도로 유지한다
3. 상세 규칙의 SSOT 는 `docs/` 다. 루트와 `.claude/rules` 는 **라우팅만** 한다
4. 도구 전용 구성(`.claude/**`, `.codex/**`)은 규칙을 복제하지 않고 같은 `docs/` 를 가리킨다
5. 구조 자체를 **기계로 검사**한다 (`tools/verify-instructions.sh`)

## 근거

- 조건부 로딩이 되는 것은 path-scoped rule 뿐이다. 일반 import 는 파일만 나눌 뿐 시작 컨텍스트를 줄이지 못한다
- Codex 는 루트에서 CWD 까지 지침 체인을 만들며 합산 한도가 있다. 짧은 루트 + 명시적 라우팅 표가 두 도구 모두에 통한다
- 규칙을 도구별 파일에 복사하면 반드시 갈라진다. 참조는 갈라지지 않는다

## 결과

- 좋아진 것: 상시 컨텍스트 감소, 이중 유지보수 제거, 구조 위반의 조기 발견
- 대가: 계층이 하나 늘어 "어디에 쓸지" 판단이 필요하다 — 그 판단 기준을 `instruction-maintenance.md` 에 명시했다
- 새 규칙은 승격 절차를 거친다. 한 번의 실수가 곧바로 상시 지침이 되지 않는다

## 대안과 기각 사유

| 대안 | 기각 사유 |
|---|---|
| 루트 한 파일 유지 | 컨텍스트 비용이 세션마다 발생. 중요 규칙이 묻힘 |
| 도구별 파일에 각각 상세 규칙 | 이중 유지보수. 반드시 어긋남 |
| 모든 규칙을 rule 로 쪼갬 | 경로가 안 맞으면 아예 안 읽힘. 치명적 불변식은 루트에 있어야 함 |
