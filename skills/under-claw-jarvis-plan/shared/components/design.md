# 디자인 구성 모듈

출처: https://github.com/nexu-io/open-design. 원본 라이선스는 components.json과
해당 고정 revision의 LICENSE를 따른다. 아래는 독립적으로 작성한 연결 규칙이다.

- 기존 브랜드 규약·DESIGN.md·디자인 시스템을 먼저 읽고 색상·서체·간격·구성요소를
  작업 명세에 연결한다. 새 규약 파일은 실제 재사용할 디자인 결정이 있을 때 작성한다.
- 기능 스킬(어떻게 만드는가), 디자인 규약(어떤 스타일인가), 템플릿(시작 파일)을
  구분한다. 사용 가능한 문서·슬라이드·이미지·프론트 도구를 작업에 맞게 선택한다.
- 생성 후 실제 렌더링을 확인한다. 목표 화면 크기별 잘림·겹침·읽기 쉬움·반응형·
  주요 상호작용을 검사하고 산출물과 캡처를 evidence에 함께 묶는다.
- 표현 수정은 구현/시각 검수로 돌아간다. 브랜드 방향이 틀렸으면 계획으로 돌아간다.
- OpenDesign 연결이 있으면 현재 프로젝트의 실제 파일을 읽는다. 설치되지 않았으면
  호스트의 기존 제작 도구를 사용한다. HTML 시안을 완성된 앱으로 보고하지 않는다.
- 앱 설치, 모델 연결, 게시·배포는 디자인 생성과 별도 행동이다. 기존 사용자 권한을 따른다.
