# 한국어 윤문 구성 모듈

출처: https://github.com/epoko77-ai/im-not-ai (MIT).
사용자에게 전달하는 한국어 문서의 표현을 다듬을 때만 적용한다.
코드·명령·API 필드·실행 명세의 제약을 문체 개선 목적으로 바꾸지 않는다.

1. 독자·장르·어조를 확인하고 번역투·기계적 나열·불필요한 접속사 등 실제 문제 구간을 찾는다.
2. 의미·사실·금액·날짜·고유명사·직접 인용을 고정하고 문제 구간만 수정한다.
   명확한 문서는 추가 에이전트 없이 소규모 수정 또는 무변경으로 끝낸다.
3. 구조적 문제가 클 때만 진단→윤문→원문 대조로 나눈다. 원본의 고정 변경률 임계값을
   모든 장르에 일괄 적용하지 않고 실제 수정 범위와 의미 변화 여부를 확인한다.
4. 수치·인용 diff와 원문/최종 문서의 의미 대조 기록을 검증 증거로 남긴다.
   한국어 문체 휴리스틱은 AI 작성 여부의 증명이나 탐지기 우회 보장이 아니다.

현재 세션에서 원본 humanize-korean을 사용할 수 있고 호출 조건이 충족되면 그 기능을
사용한다. 미설치이면 위 방법론으로 처리하고 원본 스킬을 실행했다고 표현하지 않는다.
