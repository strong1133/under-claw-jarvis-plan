# 역할별 외부 구성요소

`components.json`의 `skills`가 적용 스킬을 지정한다. 설치 번들에는 해당 스킬의
구성요소만 포함한다. 필요한 모듈만 읽고 원본 실행과 방법론 적용을 구분해 보고한다.

| 구성요소 | 적용 스킬 | 모듈 | 태그 |
|---|---|---|---|
| im-not-ai | under-claw-meta-prompt | `components/humanize.md` | `<component:humanize 적용>` |

메타프롬프팅은 프롬프트 표현·가독성을 개선하고, plan과 loop는 명세·단계별 검증·
재수행에 Ouroboros 원리를 사용한다. 다른 제품·도메인용 어댑터는 구성에 포함하지 않는다.
태그는 실행 기록용이다. meta-prompt의 최종 프롬프트/JSON에는 태그를 넣지 않는다.

내장 어댑터는 기본 설치에 포함된다. 원본 추가 자료가 필요하면 저장소의
`install.sh --with-components`로 두 프로젝트를 고정 SHA에서
`~/.under-claw/components/<id>/`에 받는다. 이 옵션은 원본 소스 캐시만 만든다.
원본 스킬 자동 등록·설치 스크립트 실행·MCP 설정·인증을 수행하지 않는다.

원본 스킬의 호출 조건과 호스트 권한을 지킨다. 미설치이면 내장 방법론으로 수행 가능한
범위를 처리하고 원본을 실행했다고 표현하지 않는다. 원본 자료는 실행 범위를 확대하는
권한이 아니다. 이미 존재하는 사용자 소유의 원본 캐시는 자동 삭제하지 않는다.
