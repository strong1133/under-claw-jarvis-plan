작업을 완료 선언하기 전 검증을 수행한다.

1. 아래를 순서대로 실행한다. 앞 단계가 실패하면 **거기서 멈추고** 원인부터 보고한다.

```bash
{{BUILD_CMD}}
{{ARCH_TEST_CMD}}
./tools/verify-instructions.sh
```

   {{런타임 버전 문제 발생 시 조치 — 예: JAVA_HOME=$(/usr/libexec/java_home -v 21) 를 앞에 붙인다}}

2. 변경된 파일에 대응하는 테스트가 있으면 그것만 실행한다. 전체 테스트는 사용자가 요청했을 때만.

3. 보고 형식:
   - 통과한 명령은 한 줄로만 (`{{BUILD_CMD}} ✓`)
   - 실패는 **명령 / 원인 / 파일:줄 / 제안 조치**. 자동검증 실패는 위반한 룰 이름을 그대로 인용
   - 실패를 임의로 고치지 말고 먼저 보고한다. 이미 수정 지시를 받은 상태면 고친 뒤 재검증한다

4. 통과하지 않은 항목이 하나라도 있으면 "완료"라고 말하지 않는다.
