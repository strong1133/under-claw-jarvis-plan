# 메타프롬프팅의 한국어 표현 개선

출처: https://github.com/epoko77-ai/im-not-ai (MIT).
`under-claw-meta-prompt`의 최종 표현 점검에만 적용한다.

1. 질의에서 요구·제약·성공 기준을 먼저 추출하고 프롬프트 초안을 완성한다.
2. 한국어 설명문의 번역투, 중복 수식, 불필요한 접속사, 모호한 표현, 비유·수사로 돌려 말한 표현을 찾아 필요한 구간만 수정한다.
   명확한 초안은 무변경으로 끝낸다. 단순 초안에 다중 에이전트·추가 호출을 강제하지 않는다.
3. 지시의 강도(필수/선택/금지), 조건·예외, 부정문, 수치·단위·기한, 변수, 코드,
   경로·호출 토큰·직접 인용은 보존한다. 실행 순서와 성공 기준은 표현 개선으로 바꾸지 않는다.
   프롬프트의 번호·불릿·반복 제약은 의도적일 수 있으므로 AI 문체라는 이유만으로 삭제하지 않는다.
4. 일반 모드는 기존 9개 섹션과 순서를 유지한다. `--spec`는 자연어 값의 표현만 검토하며
   JSON 키·타입·criterion ID·required·stage와 의미를 보존하고 공통 스키마를 다시 검사한다.
5. 원질의↔초안↔개선본을 대조한다. 의미나 요구 강도가 달라졌으면 그 수정을 되돌린다.
   비한국어 프롬프트와 코드/데이터 원문은 이 한국어 윤문 경로를 생략한다.

현재 세션에 원본 humanize-korean이 있고 호출 조건이 충족되면 선택적으로 사용한다.
미설치이면 위 방법론으로 점검한다. 원본의 전체 진단 파이프라인을 실행했다고 주장하지 않는다.
점검 기록·태그를 최종 프롬프트/JSON에 섞지 않고 기존 응답·클립보드·저장 계약을 유지한다.
